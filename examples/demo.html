Ultra-Lightweight

Wee

A dedicated, distraction-free local HTML viewer written in Rust.

Keyboard Shortcuts

Reload Page Ctrl+R or F5
Quit Wee Ctrl+Q
Toggle DevTools F12
Navigate Back Alt+Left
Navigate Forward Alt+Right

Core Features

  • Native System Webview: Powered by wry and tao for near-zero memory footprint and fast startup.
  • Safe Asset Resolution: Handles relative styles, scripts, and media via custom protocol.
  • Smart Link Interception: External links like GitHub Repository open automatically in your default browser.
  • Live Reload (-w): Watches local files and auto-refreshes when saved.
  • Zero Clutter: Minimal chrome focused 100% on your content.
